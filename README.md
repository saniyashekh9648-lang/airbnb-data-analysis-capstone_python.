# Airbnb Data Analysis using Python

## Project Overview

This project explores Airbnb listing data using Python to understand pricing, availability, room types, and other patterns in the dataset.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- SQLite
- SQL

## Key Analysis

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Price and availability analysis
- Room type analysis
- Location-based analysis
- Data visualization
- SQL-based data exploration

## Project Files

- Air_Bnb_EDA.ipynb – Python-based exploratory data analysis
- Airbnb_Data_Exploration_Using_SQLite... – SQL and Pandas analysis
- README.md – Project documentation

## Learning Outcome

This project helped me practice data cleaning, exploratory analysis, SQL queries, visualization, and extracting insights from real-world data.

## Source / Attribution

This repository was developed by studying and adapting an existing public Airbnb EDA project.
